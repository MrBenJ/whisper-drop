# Bundled fonts

Both families ship with the app as local woff2 files so the renderer never
fetches from the network. Both are licensed under the SIL Open Font License,
Version 1.1 (https://openfontlicense.org).

- **Lato** (regular, italic, bold) - Copyright (c) 2010-2014 Lukasz Dziedzic,
  with Reserved Font Name "Lato". https://fonts.google.com/specimen/Lato
- **Josefin Sans** (semibold, bold) - Copyright 2010 The Josefin Sans Project
  Authors. https://fonts.google.com/specimen/Josefin+Sans

The woff2 files here are the latin subsets as served by Google Fonts.
